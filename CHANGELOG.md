# Changelog

All notable changes to OpenRund are documented here.

## 2.0.0 — 2026-08-04

- Ships the complete governed runtime as a typed Python package for Python
  3.12 and newer.
- Provides the authoritative Engine, immutable contracts, canonical codecs,
  deterministic Views, SQLite custody, built-in Capabilities, provider
  adapters, durable model loop, `.orun` Bundles, local assembly, operator
  service, and installed command.
- Includes a deterministic offline governed-coding demonstration and a fully
  Python verification and release workflow.
