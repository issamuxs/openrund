# Milestone v1.1: Runtime Hardening And Governance Cutover

**Status:** Shipped with acknowledged deferred artifacts on 2026-05-13
**Phases:** 06-10
**Total Plans:** 32
**Archive mode:** reconstructed from phase artifacts because active roadmap files had already advanced to v1.2.

## Overview

v1.1 hardened OpenRund from a v1.0 MVP runtime into a stricter governed runtime
surface. The milestone cleaned repository hygiene, hardened SDK/runtime entry
points, added `.orun` portability, added coding-agent substrate capabilities,
performed the canonical ontology cutover, introduced first-class governance and
Command decision semantics, finalized CLI explanation surfaces, and replaced
the old split demo strategy with one flagship governed coding run.

The milestone was closed after acknowledging stale audit/open-artifact state.
The current code and phase artifacts show completion of the later v1.1 work,
but the original v1.1 audit remains archived with `gaps_found` because it was
created before Phases 8-10 and later inserted Phases 8.5, 8.75, and 8.8 were
completed.

## Milestone Summary

**Key decisions:**

- OpenRund's differentiator is semantic authority control over
  model-proposed side effects, not lifecycle control or durability alone.
- Approval is not legality; illegal operations are rejected while valid
  operations requiring authorization are deferred with a Wait.
- CLI surfaces explain runtime-provided Command decisions, Receipts, and Views;
  they do not decide legality.
- The public MVP example is one flagship governed coding run.
- Compatibility-zone migration was rejected for production semantics; canonical
  ontology names must be used across code, tests, examples, docs, configs, and planning.

**Issues resolved:**

- Repository hygiene and generated-output policy became enforceable.
- Public SDK/runtime assembly became explicit.
- `.orun` export/verify/replay/import/resume became fail-closed and portable.
- Process and git capabilities became governed substrate capabilities.
- Stale pre-canonical run/view/check naming was removed from production surfaces.
- Demo output now proves the core governance loop from runtime facts.

**Issues deferred or acknowledged at close:**

- 10 open artifacts were acknowledged as deferred in `.planning/STATE.md`.
- The archived v1.1 audit remains `gaps_found` because it predates later phase execution.
- v1.2 will perform a skeptical governance audit before further launch claims.

**Technical debt:**

  had already advanced to v1.2.
