## Overview

v2.0 turns the established governed-runtime semantics into one idiomatic Python product without changing canonical history or portable wire data. Work begins by freezing the current executable behavior as inert compatibility evidence, then establishes Python contracts, replay facts, durable storage, Engine authority, governed coordination, external effects, providers, and Bundles in dependency order. The installed assembly, CLI, and flagship demonstration arrive only after those semantics are stable; the final cutover removes every live Node, pnpm, JavaScript, and TypeScript surface after frozen-fixture, cross-read, package, and end-to-end gates prove the Python runtime can stand alone.
