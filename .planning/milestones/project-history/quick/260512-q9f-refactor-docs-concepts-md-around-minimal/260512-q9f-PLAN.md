# Quick Plan: Refactor `docs/concepts.md` Around Minimal Ontology

## Goal

Replace the implementation-surface taxonomy in `docs/concepts.md` with a small
semantic graph:

`Run -> Command -> Event`, with Messages, ModelCalls, Actions, Waits,
Delegations, Checks, Checkpoints, Annotations, Artifacts, Capabilities,
Authority, Leases, Bundles, and Views.

## Tasks

1. Rewrite the ontology backbone.
   - Define supreme rules: events are canonical, concepts earn identity,
     discriminators beat subtype nouns, and indentation means containment.
   - Use singular semantic nouns and explicit relationship/value-type sections.

2. Add legacy mapping without claiming migration is complete.
   - Map current terms/events to canonical concepts.
   - Keep current persisted literals described as compatibility/current
     implementation names until a code migration occurs.

3. Verify.
   - Run docs/public API tests.
   - Run stale ontology guard.
   - Run hygiene/typecheck.
