**Gathered:** 2026-05-11
**Status:** Complete

## Task Boundary

The runtime demo surface still had three developer-experience issues after the
operator surfaces were promoted into the framework:

- Governed write approval showed a requested draft path and a default approved
  path without explaining that the former is the proposed draft artifact and
  the latter is the final governed output location.
- The generic completion summary listed status, paths, and proof in an order
  that did not match how developers orient themselves.
- Milestone output was event-subscriber based, but plain `console.log` made the
  terminal experience look batched during fast execution.

User decision:

- Session ID, model provider, runtime home, and workspace should appear at the
  start when already known.
- Final summary should be logically grouped.
- The line streaming surface should be framework-generated, not demo-specific.
