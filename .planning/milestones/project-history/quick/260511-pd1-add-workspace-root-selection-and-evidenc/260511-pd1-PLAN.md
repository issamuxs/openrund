# Quick Task 260511-pd1 Plan

## Task 1: Add Session Workspace Root Helper

**action**

- Add a runtime helper that returns the default workspace root for a session:
  `~/.openrund/sessions/<sessionID>/workspace`.
- Export the helper from `@openrund/runtime`.
- Use it in the research-brief demo for developer runs.
- Keep explicit test injection unchanged.

**verify**

- Unit test default workspace path.
- Demo no-provider path does not create temp workspaces.

## Task 2: Prompt/Select Workspace For Demo Work Products

**action**

- In interactive developer runs, ask for workspace root with Enter accepting the default session workspace.
- In automated or test runs, use the provided workspace root or default session workspace.
- Mount source/project, drafts, and approved outputs under the selected workspace root.
- Update demo docs so runtime home and workspace root are distinct.

**verify**

- Demo output paths no longer contain OS temp folders for developer defaults.
- Fixture tests continue to use injected temp roots.

## Task 3: Evidence-Backed Reconciliation

**action**

- After an unknown action outcome, collect deterministic filesystem evidence for the candidate receipt.
- Validate evidence into candidate outcomes: `completed`, `failed`, or `still_unknown`.
- Manual operator flow displays observed facts and candidate outcome, then asks whether to record it.
- Automated flow records only when the deterministic evidence supports completion.
- Store evidence source, observed path, existence, size, hash, validator, candidate outcome, and operator/policy decision in reconciliation evidence.

**verify**

- Tests assert reconciliation evidence includes deterministic observation fields.
- Demo trace presents evidence facts before operator approval.
