## Scope-sanity rationale

Plan 02 intentionally retains ten files across three non-overlapping tasks because all later plans require the same atomic constructor foundation: Task 01 establishes the shared exception and ID types, Task 02 builds immutable JSON/time values on them, and Task 03 applies those errors and exact-value rules to paths. Moving Task 02 or Task 03 into Plan 03 would mix primitive boundary construction with the larger ontology, increase that plan's file/context load, and delay both parallel branches that depend on the complete foundation. No task modifies more than five files, and each task has its own focused automated command.

## Trust Boundaries

| Boundary | Description |
|---|---|
| caller values → semantic constructors | Dynamically typed Python inputs become trusted immutable domain values. |
| PathLike → normalized path | User-controlled path representations cross into filesystem- or wire-facing contracts. |
| infrastructure failure → caller-visible error | Internal failures must remain classifiable without leaking sensitive detail. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-28-02-TYPE | Tampering | ID/JSON/time constructors | high | mitigate | Validate runtime kind before coercion, check boolean before integer, reject empty required values, and deep-freeze all nested inputs. |
| T-28-02-PATH | Elevation of Privilege | `LocalPath` / `PortablePath` | high | mitigate | Reject bytes, NUL, roots/drives/traversal/backslashes at the applicable boundary and keep lexical normalization distinct from filesystem containment. |
| T-28-02-ERROR | Information Disclosure | Semantic exceptions | high | mitigate | Use stable codes and bounded safe fields; exclude raw bodies, bytes, credentials, and private absolute paths from messages and reprs. |
| T-28-02-UNICODE | Tampering | JSON/path string values | medium | mitigate | Preserve exact code points and test composed, decomposed, BMP, and astral inputs without normalization. |
