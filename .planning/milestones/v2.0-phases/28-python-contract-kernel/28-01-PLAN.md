## Trust Boundaries

| Boundary | Description |
|---|---|
| package metadata → build frontend | Repository configuration selects code and data placed in published artifacts. |
| manifest path → local filesystem | Manifest-controlled relative paths identify bytes read as frozen evidence. |
| evidence bytes → tests | Untrusted or tampered bytes must be authenticated before semantic interpretation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-28-01-CORPUS | Tampering | `tests/conftest.py` corpus loader | high | mitigate | Resolve beneath a fixed root, lstat every component, require regular files, and verify byte length plus SHA-256 before parsing. |
| T-28-01-PATH | Elevation of Privilege | Manifest relative paths | high | mitigate | Reject absolute paths, parent traversal, symlinks, and any resolved target outside the committed corpus root. |
| T-28-01-PKG | Tampering | Python build inputs | medium | mitigate | Commit `uv.lock`, require `uv lock --check`, inspect wheel members, and test the installed wheel in isolation. |
| T-28-01-MUT | Tampering | Frozen corpus tree | high | mitigate | Expose bytes through read-only helpers and compare corpus path/size/hash/mtime digests before and after adversarial tests. |
</threat_model>
