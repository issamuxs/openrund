# Project Milestones: OpenRund

## v2.0 Python OpenRund (Shipped: 2026-08-06)

**Status:** Complete with historical workflow metadata acknowledged.

**Delivered:** One typed, dependency-free Python runtime for durable governed
agent Runs, with the Engine as the sole legality authority.

**Scope:** Phases 27–37; 78 plans; 38/38 requirements satisfied.

**Key accomplishments:**

- Immutable typed contracts, exact codecs, and authenticated compatibility
  evidence for canonical runtime data.
- Deterministic replay Views plus durable SQLite Event, Artifact, and Lease
  custody.
- One Engine-owned Command path for Run, model, Wait, approval, Authority,
  Action, reconciliation, Delegation, join, and Check semantics.
- Governed filesystem, Markdown documents, bounded process, and Git
  Capabilities plus provider-neutral model adapters and durable execution.
- Portable `.orun` export, verification, replay, import, and conditional resume
  assessment.
- Stable Python assembly, operator interface, installed command, interactive
  workspace selection, and production-assembly demonstration.

**Verification:** 974 tests passed with 3 opt-in provider checks skipped;
Python 3.12–3.14, strict typing, Ruff, package contents, wheel, source archive,
security, and milestone audit gates passed.
